# java-racingcar-precourse

## 요구 사항 분석 + 추가 고려 사항 기재
### 📗 기본 조건
- 입력
    - 경주할 자동차 이름 (쉼표 기준으로 *붙여서 입력 받고* 구분)
    - 시도할 횟수
- 출력
    - 횟수(차수) 마다의 각 경주 자동차 전진 실행 결과
    - 최종 우승자 (다수일경우 이름 중간에 쉼표+띄어쓰기로 구분)
- 동작
    - 0 ~ 9 사이에서 랜덤값을 구한 후 4 이상일 경우 전진
    - 0 ~ 9 사이에서 랜덤값을 구한 후 3 이하일 경우 정지(전진 X)
    - 횟수(차수)가 끝날 때의 전진 값 중 가장 큰 값을 가진 자동차(이름)가 우승

### 🚫 명시된 제약 사항
- 자동차 이름은 5자 이하만 가능
- 자동차 이름은 쉼표(띄어쓰기X) 구분
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료

### ⚠️ 시행해야 하는 예외 처리
- 자동차 이름 입력에서
    - 자동차 이름이 5자 초과일 때 예외 </br>
      → 쉼표가 아닌 다른 구분자를 사용하여 파싱한 경우도 이 경우로 예외 처리
    - 만약 구분자로서 쉼표와 띄어쓰기가 혼용되어있는데 5자 이하일 경우는? <br>
      → 구분된 자동차 이름이 띄어쓰기로 시작하거나 끝나는지 확인 후 예외 처리
    - 빈 입력 예외 - 입력 자체가 빈 값 / 입력 파싱 값(자동차 이름) 중 빈 값 존재 두 가지 경우 모두 처리
- 몇 번 이동할 것인지 입력 받는 부분에서
    - 숫자가 아닐 경우 예외
    - 0 이하일 경우 예외
    - 정수 범위 벗어날 경우 예외

## 🛠️ 기능 구현 목록
- [X] 입력 뷰 구현
  - [X] 자동차 이름 리스트 입력
    - [X] 입력 자체가 빈 값인 경우 예외 처리
  - [X] 이동 횟수 입력
    - [X] 숫자가 아닐 경우 예외
    - [X] 0 이하일 경우 예외
    - [X] 정수 범위를 벗어날 경우 예외 
  - [X] 이동 횟수 입력에 대한 Validation 후 Type Casting 반환 구현 <br><br>
  
- [X] 자동차 이름 입력에 대한 Parser 구현
  - [X] 쉼표 ( , ) 기준으로 파싱 후 자동차 이름 리스트로 저장
    - [X] 파싱된 자동차 이름이 빈 값일 때 예외 처리
    - [X] 자동차 이름이 5자 초과일 때 (다른 구분자 사용 포함) 예외 처리
    - [X] 구분자로서 쉼표 앞뒤로 띄어쓰기가 혼용되었지만 파싱 값이 5자 이하일 때 <br>
          파싱된 자동차 이름이 띄어쓰기로 시작되거나 끝나는지 확인, 이 경우 예외 처리 <br><br>

- [ ] 출력 뷰 구현
  - [ ] "실행 결과" 출력
  - [ ] 횟수(차수) 마다의 각 경주 자동차 전진 실행 결과 출력
    - [ ] 횟수(차수) 마다 Car List에 대해 자동차 name과 position을 포맷에 맞게 출력
  - [ ] 최종 우승자 출력 (우승자가 다수일 경우 이름 사이 쉼표+띄어쓰기로 구분) <br><br>

- [X] Car 구현
  - [X] 필드로 name과 position을 가짐
  - [X] 입력 받은 이름에 대해 Car("name", 0) 으로 객체를 생성 
  - [X] 전진 메서드 - 0 ~ 9 사이에서 랜덤값을 구한 후 4 이상일 경우 전진 (position++) - 구현 <br><br>

- [X] Judgment 구현
  - [X] 횟수(차수)가 끝날 때의 Car List의 position 값 중 가장 큰 값을 가진 자동차(들)을 반환하도록 구현
  - [X] 우승 자동차(들)의 이름을 반환하도록 구현 <br><br>

- [X] RacingGame 구현
  - [X] 자동차 이름 리스트에 대해 Car List로 생성, 관리
  - [X] 한 차수 실행 구현
  - [X] 전체 차수 실행 구현 <br><br>

- [ ] GameController 구현
  - [ ] 입력 관할
  - [ ] 입력값에 대한 전체 차수 실행 (GameConfig)
  - [ ] 전체 차수 실행 결과에 따른 출력 관할
  - [ ] 전체 차수 실행이 끝나면, 애플리케이션은 정상 종료된다고 가정
